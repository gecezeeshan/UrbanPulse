# UrbanPulse AI

Smart City Incident Intelligence Multi-Agent System.

## Tech Stack

- React + Vite
- Node.js + Express
- OpenAI GPT-4.1
- Embeddings + Similarity Search

## Backend Setup

cd backend

npm install

cp .env.example .env

npm run dev

## Frontend Setup

cd frontend

npm install

npm run dev

## API Endpoints

GET /api/incidents

POST /api/classify

POST /api/severity

POST /api/similarity

POST /api/incident"# UrbanPulse"
